# cookie

TypeScript製のHTTP Cookieユーティリティライブラリです。`Cookie` / `Set-Cookie` ヘッダーのパースとシリアライズ、Web Crypto API（HMAC/SHA-256）を使った署名・検証、そしてシークレットローテーションをサポートします。

## 特徴

- **型安全**: TypeScriptで書かれており、完全な型定義を同梱
- **非同期対応**: `async/await` ベースのAPI
- **署名機能**: Web Crypto APIを使ったHMAC/SHA-256署名で改ざんを検出
- **シークレットローテーション**: 複数のシークレットを使い回せるため、既存クライアントを壊さずに安全にシークレットを更新可能
- **UTF-8サポート**: 日本語などのマルチバイト文字を問題なく扱える
- **標準的なデフォルト値**: `Path=/`・`SameSite=Lax` などのセキュアなデフォルトをビルトイン

## インストール

```bash
# npm
npm install @your-org/cookie

# yarn
yarn add @your-org/cookie

# pnpm
pnpm add @your-org/cookie
```

## 基本的な使い方

### Cookieの作成

`createCookie` 関数でCookieオブジェクトを生成します。

```typescript
import { createCookie } from '@your-org/cookie'

const cookie = createCookie('session', {
  maxAge: 60 * 60 * 24 * 7, // 1週間
  httpOnly: true,
  secure: true,
})
```

### シリアライズ（Set-Cookieヘッダーの生成）

```typescript
// レスポンスに Set-Cookie ヘッダーを付与する
const setCookieHeader = await cookie.serialize('user-id-123')
// => "session=dXNlci1pZC0xMjM%3D; Path=/; Max-Age=604800; HttpOnly; Secure; SameSite=Lax"

response.headers.set('Set-Cookie', setCookieHeader)
```

### パース（Cookieヘッダーの読み取り）

```typescript
// リクエストの Cookie ヘッダーから値を取り出す
const cookieHeader = request.headers.get('Cookie')
const value = await cookie.parse(cookieHeader)
// => "user-id-123"  (存在しない場合は null)
```

### JSONオブジェクトの保存

文字列以外のデータは `JSON.stringify` / `JSON.parse` と組み合わせて扱います。

```typescript
const sessionCookie = createCookie('session', { httpOnly: true, secure: true })

// 書き込み
const data = { userId: 42, role: 'admin' }
const setCookieHeader = await sessionCookie.serialize(JSON.stringify(data))

// 読み込み
const raw = await sessionCookie.parse(request.headers.get('Cookie'))
const session = raw ? JSON.parse(raw) : null
// => { userId: 42, role: 'admin' }
```

## 署名機能

`secrets` オプションにシークレット文字列の配列を渡すと、Cookieの値がHMAC/SHA-256で署名されます。クライアント側でCookieが改ざんされた場合、`parse()` は `null` を返します。

```typescript
const signedCookie = createCookie('signed-session', {
  secrets: ['my-super-secret'],
  httpOnly: true,
  secure: true,
})

// シリアライズ（署名付き）
const setCookieHeader = await signedCookie.serialize('user-id-123')

// パース（署名検証あり）
const value = await signedCookie.parse(request.headers.get('Cookie'))
// 署名が無効な場合は null を返す
```

### シークレットローテーション

シークレットを定期的に更新する際は、**新しいシークレットを配列の先頭に追加**します。`serialize()` は常に先頭（最新）のシークレットで署名し、`parse()` は配列内のすべてのシークレットで検証を試みます。これにより、古いシークレットで署名されたCookieを持つユーザーがログアウトされることなく移行できます。

```typescript
// ステップ1: 既存のシークレットのみ
const cookie = createCookie('session', {
  secrets: ['secret-v1'],
})

const oldSetCookie = await cookie.serialize('alice')

// ステップ2: 新しいシークレットをローテーション（先頭に追加）
const rotatedCookie = createCookie('session', {
  secrets: ['secret-v2', 'secret-v1'], // 新しいものが先頭
})

// 古いシークレットで署名されたCookieも引き続きパースできる
const value = await rotatedCookie.parse(/* 旧Set-Cookieから取得したCookieヘッダー */)
// => "alice"

// 以降のserializeは新しいシークレット（secret-v2）で署名される
const newSetCookie = await rotatedCookie.serialize('alice')
```

## APIリファレンス

### `createCookie(name, options?)`

新しい `Cookie` オブジェクトを生成します。

| 引数 | 型 | 説明 |
|------|----|------|
| `name` | `string` | Cookieの名前 |
| `options` | `CookieOptions` | (任意) Cookieのオプション |

---

### `CookieOptions`

| プロパティ | 型 | デフォルト | 説明 |
|-----------|-----|-----------|------|
| `domain` | `string` | — | Cookieのドメイン |
| `expires` | `Date` | — | Cookieの有効期限 |
| `httpOnly` | `boolean` | `false` | `HttpOnly` 属性を有効にする |
| `maxAge` | `number` | — | Cookieの最大有効期間（秒） |
| `partitioned` | `boolean` | `false` | `Partitioned` 属性を有効にする（自動的に `secure: true` になる） |
| `path` | `string` | `'/'` | Cookieのパス |
| `sameSite` | `'Strict' \| 'Lax' \| 'None'` | `'Lax'` | `SameSite` 属性 |
| `secure` | `boolean` | `false` | `Secure` 属性を有効にする |
| `secrets` | `string[]` | `[]` | 署名に使うシークレットの配列（先頭が最新） |
| `decode` | `(value: string) => string` | `decodeURIComponent` | 値のデコード関数 |
| `encode` | `(value: string) => string` | `encodeURIComponent` | 値のエンコード関数 |

---

### `Cookie` クラス

#### プロパティ（読み取り専用）

| プロパティ | 型 | 説明 |
|-----------|-----|------|
| `name` | `string` | Cookieの名前 |
| `domain` | `string \| undefined` | ドメイン |
| `expires` | `Date \| undefined` | 有効期限 |
| `httpOnly` | `boolean` | HttpOnly属性の有効/無効 |
| `maxAge` | `number \| undefined` | 最大有効期間（秒） |
| `partitioned` | `boolean` | Partitioned属性の有効/無効 |
| `path` | `string` | パス |
| `sameSite` | `'Strict' \| 'Lax' \| 'None'` | SameSite属性 |
| `secure` | `boolean` | Secure属性の有効/無効 |
| `signed` | `boolean` | シークレットが設定されており署名が有効かどうか |

#### `cookie.parse(headerValue)`

`Cookie` ヘッダーの文字列からこのCookieの値を取り出します。

```typescript
async parse(headerValue: string | null): Promise<string | null>
```

- `headerValue` が `null` または空の場合は `null` を返します。
- 指定のCookieが存在しない場合は `null` を返します。
- 署名が無効な場合は `null` を返します。

#### `cookie.serialize(value, props?)`

`Set-Cookie` ヘッダーに使用する文字列を生成します。

```typescript
async serialize(value: string, props?: CookieProperties): Promise<string>
```

- `props` を渡すと、コンストラクタで設定したオプションを上書きできます。

```typescript
// serialize 時にプロパティを上書きする例
const setCookieHeader = await cookie.serialize('hello', {
  maxAge: 3600,
  path: '/dashboard',
})
```

---

### `sign(value, secret)` / `unsign(cookie, secret)`

低レベルな署名・検証関数です。通常は `Cookie` クラスを通じて利用するため、直接使う機会は少ないですが、必要に応じてインポートできます。

```typescript
import { sign, unsign } from '@your-org/cookie/cookie-signing'

const signed = await sign('my-value', 'secret')       // => "my-value.<hash>"
const original = await unsign(signed, 'secret')        // => "my-value"
const invalid = await unsign(signed, 'wrong-secret')   // => false
```
