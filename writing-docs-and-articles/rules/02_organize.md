# Organize Sections

ツリー構造に整理された箇条書きを、構造を変えずに、章・節・段落に分割し直す。

## 前提

与えられる情報（Input）は 01_pyramid-structure.md の「出力形式」の通り。
その前提で以下に従い構成を変換する。

- ファイル先頭に `# {タイトル}` を置く。 タイトルはユーザーが考えるためこのまま。
- その下にInputの `Introduction` セクション内の箇条書きをそのまま転記。
- Inputの `Content` セクション内の箇条書きは、以下のルールで構成を変換して転記。
  - 1段目の箇条書き1つにつき `## {タイトル}` の章を1つ作る。
  - `## {タイトル}` 直下に、その1段目の箇条書きアイテムをInputからそのまま書き写す。
  - その1段目の箇条書きアイテムに紐づくサブツリーの深さが2以下の場合は、サブツリーの箇条書きを `## {タイトル}` 直下にインデントして転記する。
  - 深さが3以上の場合は、2段目の箇条書き1つにつき `### {タイトル}` の節を作り、その下にそのサブツリーをそのまま転記する。
- 全ての `{タイトル}` に、その内容を要約したタイトルをつける。

## 出力形式

```markdown
# 章タイトル

- 段落1リード文
    - 段落1の箇条書き
    - 段落1の箇条書き

## 節タイトル

- 段落1リード文
    - 段落1の箇条書き
    - 段落1の箇条書き
- 段落2リード文
    - 段落2の箇条書き
    - 段落2の箇条書き
```
